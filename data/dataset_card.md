# UCI SMS Spam Collection：阶段 2 数据卡

## 来源与许可

- 数据页：<https://archive.ics.uci.edu/dataset/228/sms+spam+collection>
- 固定下载地址：<https://archive.ics.uci.edu/static/public/228/sms%2Bspam%2Bcollection.zip>
- 下载日期：2026-09-26；压缩包 SHA-256：`1587ea43e58e82b14ff1f5425c88e17f8496bfcdb67a583dbff9eefaf9963ce3`。
- 数据页列出的许可：CC BY 4.0。引用：Almeida, T. & Hidalgo, J. (2011), *SMS Spam Collection*, UCI Machine Learning Repository, DOI 10.24432/C5CC84。
- 观察单位：一条短信。原文件每行以 `ham` 或 `spam` 标签、制表符、短信文本组成。
- 来源页面说明语料由多个早期短信集合并而来，包括 Grumbletext、NUS SMS Corpus 等；它不是当前随机抽取的手机短信样本，也未按时间排序。

## 字段字典

| 字段 | 类型 | 含义 / 用途 |
| --- | --- | --- |
| `row_id` | 正整数 | 原文件的行号，从 1 开始；用于重建划分，不进入模型。 |
| `label` | `ham` 或 `spam` | 人工/来源语料给出的目标标签。 |
| `text` | UTF-8 字符串 | 原始短信；可能含电话号码或网址，不在仓库重新分发。 |
| `normalized_text` | 派生字符串 | NFKC、大小写与空白归一化；仅用于发现相同文本及防泄漏分组。 |
| `length_characters` | 派生整数 | 原始文本字符数，用于探索分析，不在本阶段规则基线中训练。 |
| `contains_url` | 派生布尔值 | 是否含 `http(s)://` 或 `www.`，用于探索分析。 |

## 核验结果

- 原始记录 5,574；`ham` 4,827（86.6%），`spam` 747（13.4%）。
- 标签/文本缺失 0；按 NFKC、大小写、空白归一化后有 5,159 个独特文本，即重复行 415；相同归一化文本的标签冲突 0。
- 文本长度中位数：`ham` 52 字符，`spam` 149 字符。90 分位数分别为 147 与 160 字符。
- 带显式网址的 `ham` 为 2 条，`spam` 为 106 条。该标记只覆盖显式网址形式，不能识别所有链接。
- 1 条文本包含汉字；第一阶段原型对此弃权而非猜测。

## 划分与使用范围

在相同标签内部对归一化文本组使用固定随机种子 42，按约 70/15/15 划分。训练集 3,880 条，验证集 831 条，测试集 863 条。每条原始短信只分到一处，跨集合无相同归一化文本。划分清单在 `artifacts/split_manifest.json`；可用 `python -m tools.run_phase2` 重新生成。测试集未用于阶段 2 的规则基线性能报告或调参。

## 代表性、隐私与限制

语料的正常短信与垃圾短信来自不同来源，文本风格和来源可能共同影响标签；模型可能学到来源特征。语料规模和许可适合课堂实验，但不能据此声称当前实际部署效果。公开文本可能含电话号码或个人内容；本仓库不提交原始压缩包，也不在报告中展示未脱敏短信。数据没有可靠的用户属性和时间戳，不能据此做用户级独立性验证、时序外推或人口子组公平性结论。
